# Статус NEZER EMU 1.0.0

**Важно:** код написан без доступа к Windows и Qt. Он НЕ был собран и НЕ запускался автором. Первая сборка в GitHub Actions может выдать ошибки компиляции — их нужно исправить по тексту ошибки. Ничего ниже не считается «проверенным», пока не запущено на реальном ПК.

## Реализовано в коде (полноценная логика)
- Экран блокировки при каждом запуске: реальные часы/дата, «Войти в систему», свайп вверх с анимацией.
- Рабочий стол: фон, логотип, управление окном, изменение размера за края, Dock («Добавить», реальные приложения, «Все приложения», убрать через ПКМ), автодобавление Play Маркета, Free Fire, PUBG, Standoff 2, Roblox после их установки.
- Правая панель: игровое управление, громкость, поворот, полный экран, профили, APK, скриншот, экран Android, домой, настройки.
- Первоначальная настройка Android официальными средствами (sdkmanager/avdmanager), проверка системы и виртуализации, диагностика ошибок запуска.
- Установка APK (кнопка или перетаскивание) с проверкой ARM/x86 и понятными ошибками.
- Реальный FPS по счётчику кадров SurfaceFlinger; если недоступен — пишется «н/д».
- Настройки (8 разделов) сохраняются сразу: CPU, RAM, режимы, FPS 30–240, разрешения 4:3/16:10/16:9/21:9 и своё (ширина/высота/DPI), рендеринг, фоны, цвет, прозрачность Dock.
- PC Mouse Engine: Raw Input, линейная чувствительность X/Y без ускорения, ADS, DPI, отключаемое сглаживание, захват курсора, профили для игр, адаптация под соотношения сторон, мультитач через консоль эмулятора (постоянное TCP, без ADB), замер задержки и тест точности.
- Установщик EXE (Inno Setup), автосборка GitHub Actions, проверка обновлений через GitHub Releases.
- Тесты: настройки, математика мыши (линейность, DPI, ADS, соотношения сторон), разбор APK, ADB, AVD, команды касаний, версии.

## Прототип / требует проверки на живом ПК
- Встраивание окна Android Emulator через SetParent: у некоторых версий эмулятора возможны артефакты или отдельная боковая панель эмулятора. Более надёжный путь (видеопоток через gRPC) — следующий этап.
- Координаты мультитача в консоли: пиксели или 0–32767 зависят от образа — для этого есть кнопка «Проверить касание».
- Параметр частоты дисплея hw.lcd.vsync и применение FPS свыше 60 зависят от версии эмулятора.
- Раскладки кнопок по умолчанию — шаблон; под каждую игру их нужно сдвинуть в редакторе профиля.
- Фоны вырезаны из присланного макета и увеличены: ниже качеством, чем оригинал. Замените исходными фото в «Оформлении» или в `assets/`.
- Иконки приложений в Dock — упрощённые (буква на цветной плитке), настоящие иконки APK пока не извлекаются. Названия неизвестных приложений берутся из имени пакета.

## Не реализовано
- Визуальный редактор раскладки поверх игры (сейчас — таблица координат).
- Покадровый график времени кадра (сейчас — среднее время кадра и разброс по секундным замерам FPS).
- Геймпады (XInput), мультиокна, запись видео, другие языки интерфейса.
- Автоматическая установка обновлений (сейчас — проверка и ссылка на новый установщик).
- Обход античитов и защит от эмуляторов — не делается принципиально.
